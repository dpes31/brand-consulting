# Phase 2 Preview Test Script

Use a test brand with at least three obvious competitors and enter one weak/non-core candidate in `필수 검토 경쟁사`.

1. Open Strategy Settings.
2. Confirm the field label is `필수 검토 경쟁사`.
3. Copy the Step 2 prompt.
4. Confirm the prompt states:
   - no Indirect Competitor,
   - user entries are review seeds,
   - final Top 2~5 by threat score,
   - Registry JSON at the end.
5. Run Step 2 and paste/submit a valid result containing the Registry markers.
6. Move to Step 4 and copy its prompt.
7. Confirm Step 4 includes the exact selected names, rank, score, and locked scope.
8. Confirm an excluded user seed is not forced into Step 4.
9. Load an existing saved project without Registry and confirm it still opens.
10. Confirm Export PDF still produces 16:9 pages and repeat export uses the session cache.
