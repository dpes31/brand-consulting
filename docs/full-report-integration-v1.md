# 비즈넵 FULL 보고서 1차 통합본

## 기준

- `main` 기반 보고서 셸을 기준으로 한다.
- 글로벌 다크 테마를 사용하지 않는다.
- 일반 슬라이드는 밝은 중성 배경과 고대비 텍스트를 사용한다.
- Creative History와 SWOT은 사용자가 지정한 기존 다크 원본 구조를 유지한다.
- 내용이 많다는 이유로 삭제하거나 요약하지 않는다.
- 한 장에 담기 어려우면 구조적으로 페이지를 분할한다.

## 보고서 규모

- Main Deck: 40 pages
- Appendix: 8 pages
- Canvas: 1280 × 720, exact 16:9

## 유지 요소

- 좌측 내비게이션
- 챕터·제목·페이지 번호 위치
- Noto Sans KR / Montserrat
- 보라색 기본 포인트 컬러
- 하단 SO WHAT 영역
- Step 0–5의 상세 분석 구조

## 시각화 원칙

- 타임라인, 축, 화살표, 퍼널, 이슈 트리, 매트릭스, 표, 단계형 로드맵을 우선 사용한다.
- 박스는 독립 항목과 최종 의사결정에만 제한적으로 사용한다.
- 핵심 문장은 노란 형광펜 방식으로 강조한다.
- 외곽 여백과 내부 블록 간격을 축소해 16:9 화면 밀도를 높인다.

## 원본 유지 페이지

### Creative History

- 2021–2026 YTD 연도 카드 6개
- VERIFIED-VERBATIM / SOURCE-FOUND-COPY-UNVERIFIED / NOT-FOUND 상태
- Message Trajectory
- Strategic So What
- 비즈넵, 삼쩜삼, 더낸세금·혜움, SSEM·쌤157 각각 1페이지

### SWOT

- 상단 governing message
- Strength / Weakness / Opportunity / Threat 4분면
- 원본 다크 배경과 사분면별 선 색상
