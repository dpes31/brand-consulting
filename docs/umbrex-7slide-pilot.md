# Main-preserving Umbrex 7-slide comparison pilot

## Owner-approved direction

The main-branch report shell is the baseline. This pilot does not redesign the entire report and does not summarize or delete content.

Preserved:

- left navigation;
- 1122 × 794 slide geometry and existing margins;
- breadcrumb, title, page-number positions;
- Noto Sans KR / Montserrat typography and violet accent;
- bottom implication area;
- identical source content between Before and After.

Changed:

- the accidental dark theme is replaced with a high-contrast light neutral theme;
- body information is restructured with axes, connectors, arrows, tables, funnels, trees, timelines, and selective area division;
- boxes are limited to independent items or decisions;
- key statements receive restrained yellow highlighter emphasis.

## Umbrex use

Umbrex is referenced as an information-structure library, not as a visual skin. The seven examples use the following structural families:

1. Growth Story — timeline / phases chart;
2. Competitor Deep Dive — business system / linear process;
3. Product Matrix — comparative table / matrix;
4. AIPL bottleneck — funnel / customer phases;
5. Creative History — evolution timeline;
6. SWOT / Root Cause — issue tree;
7. Four strategies — decision diagram / comparative table.

## Preview contract

- Seven Before/After pairs.
- The content arrays are shared by both versions so the After slide cannot delete text.
- Before reproduces the box-heavy use of the main template.
- After changes only the information structure.
- Route: `/?pilot=umbrex-compare`.

## Safety

- Branch starts from `main`.
- Draft PR only.
- No compiler, prompt, template, PDF, or production changes.
- Full-report expansion begins only after the owner approves these seven design patterns.
