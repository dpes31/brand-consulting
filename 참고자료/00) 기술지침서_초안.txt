## 1. 프로젝트 아이텐티티 (The DNA)
- **목표**: 광고 대행사의 경쟁 PT 전 '전략의 단초'를 도출하기 위한 '시장(자사, 경쟁사, 소비자, 광고 커뮤니케이션, 등) 리서치'와 **전문가용 고밀도 전략 엔진**.
- **페르소나**: 맥킨지 매니저의 논리 + 오길비 CD의 통찰력을 가진 **20년 차 시니어 플래너**.
- **철학**: Apple 수준의 압도적인 UX/UI. 단순히 기능을 넘어 '영감'을 주는 도구를 지향.

## 2. 하이브리드 워크플로우 (Zero-Fail Hybrid Flow)
사용자의 API 키 연동 여부에 따라 시스템이 **물리적으로 다르게 작동**해야 함.

### [A] API 연동 모드 (Gemini 1.5 Pro)
- **자동 리서치**: Gemini의 'Grounding(실시간 검색)' 기능을 활용하여 실제 시장 데이터를 수집.
- **팩트 체크**: **절대 가짜 데이터를 만들지 말 것.** 조사가 불가능할 경우 "데이터를 찾을 수 없습니다"라고 정직하게 보고하고 사용자가 수동 개입할 수 있도록 유도할 것.
- **출력**: 수집된 데이터를 바탕으로 `04) 컨설팅 문서 양식 참고' 템플릿에 데이터 주입.

### [B] 수동 가이드 모드 (Manual Briefing)
- **프로세스**: API가 없을 경우 시스템이 중단되는 것이 아니라, **'브리핑 팝업'**을 통해 단계별로 회장님의 프롬프트(참고자료 : 01) 브랜드 컨설팅 오팔 노드 및 프롬프트 정리, 03) 컨설팅 분석 부가 참고자료)를 사용자에게 가이드함.
- **인터랙션**: "한 번에 하나씩" 날카로운 질문을 던져 사용자가 입력한 내용을 바탕으로 보고서를 생성.

## 3. 핵심 전략 알고리즘 (Strategic Brain)
다음 5가지 핵심 참고자료(`참고자료` 폴더)의 로직을 시스템 코드에 고정(Hard-coding)할 것.

1.  **GEMS 알고리즘**: $$Result = \{Context \times (Logic + Psychology)\} \to Narrative^{Feedback}$$
2.  **ToT (생각의 나무)**: 하나의 결론을 내기 전 3가지 경로(기능적, 정서적, 문화적)를 내부적으로 비교 분석.
3.  **Creative History (Verbatim)**: 광고 히스토리 정리 시 반드시 **"실제 카피 문구(Verbatim)"**를 원문 그대로 추출. (요약 금지)
4.  **역발상 아이디어**: Phase 3 단계에서 항상 기존 문법을 뒤집는 '폭발적인 제안' 하나를 포함. (참고자료 : 02) 역발상 아이디어 도출법 참고, 05) AI 창의력 조절 방법_컨설팅 보고서 및 전략, 크리 기획시 참고)
