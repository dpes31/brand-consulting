### 트랙 B: API 모드 — template.html CSS 리뉴얼 + 컴파일러 강화

**목표**: 기존 22개 장표 구조는 유지하되, 디자인 품질을 대폭 개선

> ⚠️ **솔직한 의견**: 컴파일러 프롬프트만으로 "완전한 해소"는 어렵습니다.
> 22개 고정 장표 안에서 최대한 개선하는 것이지, 트랙 A의 자유도에는 미치지 못합니다.
> 그러나 다음 개선만으로도 **현재 대비 체감 품질이 크게 올라갈 것**입니다.

**template.html CSS 리뉴얼 방향** (SKILL.md + all_brands_design.txt 기반):

#### 1. 컬러 시스템 전면 개편
```
현재: 남색(#0a2540) + 민트(#00d4aa) — 단조롭고 모든 브랜드 동일
개선: CSS 변수를 "조사 대상 브랜드의 톤"에 맞게 동적 적용
```
- 컴파일러가 브랜드명을 보고 `:root` CSS 변수의 컬러를 자동 조정
- 58개 브랜드 레퍼런스에서 가장 가까운 컬러 톤 추출

#### 2. 타이포그래피 개선 (Stripe/Apple 참고)
```
현재: Noto Sans KR 26px 900 + 12px 기본
개선: 디스플레이용 큰 제목 (Apple 스타일 tight line-height)
      + 충분한 여백 + 계층 명확화
```
- 제목: 더 크게 (32~40px), 더 가벼운 무게 (500~600), tight line-height (1.1)
- 본문: 14px → 13px로 줄이되, line-height 1.5로 가독성 유지
- 핵심 수치: 40px+ bold로 대폭 강조

#### 3. 레이아웃 개선
```
현재: padding: 40px 60px 85px → 하단 여백 과다
      .box > dl > dt/dd — 모든 슬라이드 동일 구조
개선: 슬라이드 유형별 다른 내부 레이아웃
      포지셔닝 맵 화살표 → AI가 데이터 기반으로 SVG 배치
```
- `implication-bar` 하단 고정 바 → 더 세련되게 (Stripe 스타일 그라데이션)
- `.box` 카드 스타일 → 다중 그림자 (Stripe 스타일 blue-tinted shadow)
- 포지셔닝 맵: CSS `::after` 고정 화살표 제거 → AI가 데이터에 맞게 배치

#### 4. 시각화 요소 추가
```
현재: 텍스트만 (dt/dd 나열)
개선: CSS 기반 바 차트, KPI 카드, 트렌드 표시기
```
- `.chart-bar-bg`/`.chart-bar-fill` 클래스를 활용한 CSS 바 차트
- KPI 수치 카드: 큰 숫자 + 작은 레이블 + 트렌드 화살표
- SWOT: 4분면 색상 구분 (S=초록, W=빨강, O=파랑, T=주황)

#### 5. 컴파일러 프롬프트 강화
- "단순 플레이스홀더 교체"에서 → "디자인 사고를 적용한 시각적 편집" 으로 지시 변경
- CSS 변수 동적 조정 지시 (브랜드 톤)
- 각 슬라이드 유형별 구체적 시각화 가이드
